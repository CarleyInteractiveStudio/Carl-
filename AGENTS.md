# Carl Project Guidelines

- **Architecture:** Transformer-based Decoder model for autoregressive text generation.
- **File Format:** `.ccia` (Custom Carl IA) binary format for weights.
- **Language Stack:** Python for training, C++ for high-performance inference.
- **Dependencies:**
  - Python: PyTorch, NumPy, pypdf, python-docx, ebooklib, beautifulsoup4.
  - C++: Standard Template Library (STL).
- **Coding Style:** Modular, clear documentation in Spanish and English as per user request.
- **Credit:** All code must be original "from scratch" to ensure the user receives full credit for the architecture.
