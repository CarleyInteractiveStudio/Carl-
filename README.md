# Cerebral Engine

Cerebral is a bio-inspired AI engine developed in C, aiming to simulate the human brain's architecture and learning mechanisms.

## Project Structure

- `cerebral/`: Root of the engine.
  - `src/`: Source code.
    - `core/`: Fundamental neural engine (HM Neurons).
    - `modules/`: Brain area simulations (Prefrontal Cortex, Thalamus, etc.).
  - `include/`: Header files.
  - `docs/`: Documentation.
  - `tests/`: Unit and integration tests.

Refer to `cerebral/docs/DOCUMENTATION.md` for more details.
